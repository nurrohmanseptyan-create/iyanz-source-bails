# @iyanz-source/bails - Enhanced WhatsApp API

Baileys WhatsApp API dengan fitur lengkap: Support All Button, Custom Pairing, Anti Delay, Fast Respon, Anti Disconnect.

## ✨ Fitur Utama

- 🔘 **Support All Button Types**: Quick Reply, URL, Copy, Call, List, Product, Poll, Native Flow
- 🔐 **Custom Pairing Code**: 8-digit alphanumeric custom pairing
- ⚡ **Anti Delay**: Optimasi caching dan processing untuk mengurangi latency
- 🚀 **Fast Respon**: Message prioritization dan queue management
- 🔗 **Anti Disconnect**: Keep-alive, auto-reconnect dengan exponential backoff
- 🖼️ **Full Media Support**: Image, Video, Document, Album Messages
- 🤖 **AI Icon Support**: Tambahkan AI icon pada pesan
- 📊 **Poll & List Messages**: Dukungan penuh untuk polling dan list
